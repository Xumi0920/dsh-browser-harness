# v1.10 功能规划

> 状态：规划中（v1.9.5 已发布）
> 目标：把 browser-harness 从「能操作」推进到「失败可诊断、会话可收尾、平台可信」。

## 1. 版本主题

v1.10 聚焦三件事：

1. **失败可诊断**：工具失败时自动产出可复现的诊断包，而不是只返回错误码。
2. **生命周期自动化**：DSH session/task 结束时自动关闭 owned tabs、释放租约、清理 context。
3. **平台与能力收口**：macOS 真机 E2E、原生 HTML5 拖拽、快照 ref 生命周期。

L3 独立 profile/进程隔离继续不做。

### F1 自动失败诊断包

**目标**：页面工具失败时，自动收集诊断信息并写入 stateDir，错误响应带摘要与路径。

范围：

- 触发：页面操作类工具失败（导航、act、wait、extract、snapshot、upload/download 等）。
- 收集：
  - 错误 code/message/tool/action
  - 当前 URL/title/targetId
  - 截图
  - console 最近 50 条
  - network 最近 50 条 + 失败请求
  - 当前 task/lock/ownership/context 摘要
  - 最近快照摘要（节点数、快照版本）
- 写入：`<stateDir>/diagnostics/<lane>/<timestamp>-<code>/`，含 `report.json` 与 `screenshot.png`。
- 限制：默认 5s、单包 2MB；失败不能覆盖原始错误；URL query/userinfo 与输入值必须脱敏。
- 配置：`autoDiagnose: "errors" | "off"`，默认待定（建议 `errors`）。
- 测试：stale ref、click 被遮挡、wait 超时、导航失败、上传越界；确认不泄露字符串输入与文件内容。

**验收**：

1. 失败响应含 `diagnosis.path` 与关键摘要。
2. 诊断失败不影响原始错误。
3. 默认配置下不会无限增长；保留最近 N 个包。
4. 敏感字段不进入 report。

### F2 DSH session/task 结束自动清理

**目标**：session 结束时不留 owned tabs、lease 或 context。

范围：

- 调研 DSH plugin 生命周期钩子（dispose/session end）。
- 钩子可用时：按 cleanupPolicy 关闭 owned tabs，释放文件租约，dispose L2 context，写 closed tombstone。
- 钩子不可用时的兜底：manager 级 idle TTL / 下次启动清理过期租约。
- pause/resume/close 语义不变。
- 用户 tab 永远不关闭。

**验收**：

1. 模拟 session 结束：owned tab 关闭、用户 tab 保留、锁文件删除。
2. 异常退出：stale 租约按 TTL 回收，无永久锁。
3. 与现有 251 测试无回归。

### F3 macOS 真机 Chromium 集成 E2E

**目标**：macOS 上真实启动 Chrome 跑核心集成场景，不再只跑 fake CDP 单测。

范围：

- CI 增加 macOS integration job（至少覆盖 navigate/snapshot/act/tabs/task/CLI）。
- 启动 helper 支持 macOS Chrome/Chromium 路径。
- 失败时上传诊断包与截图 artifact。
- 文档补充 macOS 实测步骤。

**验收**：

1. macOS job 全绿。
2. 至少 10 个真实浏览器场景在 macOS 执行。
3. 失败时有 artifact。

### F4 原生 HTML5 drag-and-drop

**目标**：在 pointer 拖拽基础上支持原生 draggable / DataTransfer。

范围：

- 优先 `Input.setInterceptDrags` + `Input.dispatchDragEvent`。
- 不支持时 fallback 合成 DragEvent + DataTransfer，并标注限制。
- 新 fixture：原生可拖拽卡片到 drop zone。
- `browser_act drag` 增加 `mode: "mouse" | "html5"`，默认 mouse 保持兼容。

**验收**：

1. HTML5 drop zone 收到 dataTransfer 数据。
2. 旧 pointer drag 测试不回归。
3. 文档明确两种模式。

### F5 快照 generation/ref 生命周期

**目标**：分页快照的 ref 在其 generation 内稳定，旧 ref 错误可行动。

范围：

- 引入 `snapshotGeneration`/generation token；分页请求共享同一 generation。
- ref 绑定 generation；跨 generation 使用返回 `E_STALE_REF` 并提示重新快照。
- 缓存 AX tree，分页只重建选中页 boxes。
- 保持 `offset/limit/total` 契约。

**验收**：

1. 同一 generation 内不同页 ref 都有效（或明确拒绝并提示）。
2. 大页面分页性能不退化。
3. 旧 ref 错误包含新快照提示。

### F6 CLI JSON/退出码契约

- 所有命令支持 `--json`（或统一输出 schema）。
- 错误统一 stderr + 退出码：
  - 0 成功
  - 1 工具/浏览器错误
  - 2 参数/用法错误
- 文档列出每个命令的 schema。

### F7 L2 context 生命周期收尾

- session 结束时 dispose context。
- 启动时校验持久化 contextId，失效则清理。
- 继续不共享登录态。

### F8 MCP 适配层（preview）

- stdio MCP server，复用 13 个工具 schema。
- 只支持 stdio，不做 OAuth/远程传输。
- 先提供 read-only + navigate/snapshot，再逐步开放 act。
- 单测 JSON-RPC 握手、工具列表、一次调用、错误映射。

### F9 表单断言增强

- `browser_act` 增加 `expectValue` / `expectChecked` / `expectSelected`。
- 不回显敏感值；只返回是否匹配。
- 覆盖 React/Vue controlled input 与原生 select。

### F10 read-only 导航策略细化

- 明确 readOnly 下 navigate 是否允许 GET、是否允许 reload/history。
- 配置项 `readOnlyNavigation: "allow" | "block"`，默认保持兼容。
- 文档强调 GET 仍可能有服务端副作用。

## 4. 不在 v1.10 范围

- L3 独立 browser/profile/进程隔离
- 多浏览器实例编排/自动启动
- 云端浏览器网格
- 自动登录/Cookie 导入导出
- 跨主机文件租约一致性保证

## 5. 需要先确认的决策

1. `autoDiagnose` 默认值：建议 `errors`；是否需要采样/关闭开关。
2. DSH session end 钩子的可用性；不可用时是否接受 idle TTL 兜底。
3. macOS CI 的 Chrome 安装方式与 runner 成本。
4. 原生 HTML5 drag 的 CDP 方案 vs 合成事件 fallback。
5. MCP preview 是否只做 stdio + 只读子集。
6. 快照 generation 是否改变现有 ref 返回格式（建议不改变，只加 generation 字段）。

## 6. 验收指标

- 现有 **251** 测试全部通过，新增测试覆盖每项 P0/P1。
- macOS 真实 Chromium job 通过。
- 自动诊断包可在失败后 5s 内生成，且不含敏感输入。
- session 结束无残留 owned tab/lock/context。
- CLI 退出码/JSON 契约有文档和集成测试。
- 发布保持 changelog-only，历史 Release 不删除。
