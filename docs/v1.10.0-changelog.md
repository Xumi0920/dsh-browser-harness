# v1.10.0 Changelog

## 更新日志

### 新增

- **F1 自动失败诊断包**：页面工具失败时写入 `<stateDir>/diagnostics/<lane>/`，包含脱敏 URL、截图、console/network 尾部、task/lock/context 与 snapshot 摘要；错误信息附诊断路径与 summary；默认 `autoDiagnose: errors`，5s / 2MB 预算，不记录输入值。
- **F2 生命周期清理**：插件卸载与 DSH `session/disposed` 时清理对应任务；关闭 owned tabs、释放文件租约、dispose L2 context，并写 closed tombstone；用户 tab 保留。新增 `cleanupOnDispose` / `cleanupOnSessionDispose`，默认开启。
- **F4 原生 HTML5 拖拽**：`browser_act drag` 新增 `mode: "mouse" | "html5"`；HTML5 模式通过 `DataTransfer` 派发 dragstart/enter/over/drop/end。
- **F5 快照 generation / ref 生命周期**：`browser_snapshot` 返回 `generation`，分页传入同一 generation 可复用 AX 缓存与 refs；旧 generation 返回 `E_STALE_SNAPSHOT`；同 generation 跨页 refs 可解析。
- **F6 CLI JSON / 退出码契约**：新增 `docs/cli-contract.md`；统一退出码 0/1/2、stdout/stderr 规则、JSON 输出边界与错误格式。
- **F7 L2 context 收尾**：closed task 的残留 context 在 task 读取时自动 dispose；session cleanup dispose lane context 并清空持久化 contextId。

### 变更

- **F3 macOS 真机 Chromium E2E 取消/顺延**：当前无可用 macOS 环境，移出 v1.10.0 范围。
- `browser_snapshot --json` 的 generation 仅保证同 manager/进程内复用；CLI 单次调用不承诺跨进程快照缓存。
- L2 context 继续保持不共享登录态，L3 独立 profile 仍不做。

### 测试

- **202 单测 + 64 集成场景 = 266** 通过。

- `npm run verify` → **VERIFY_OK**。
